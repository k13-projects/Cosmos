# Cosmos Burger

Marketing site for **Cosmos Burger** (Burger, Chicken, Beer), a Tiger Hospitality Group concept,
smash burgers, chicken sandwiches, tenders and loaded fries in San Diego. Built with Next.js.

## Run locally

```bash
npm install
./scripts/build-assets.sh   # regenerates public/ from the client asset library (gitignored)
npm run dev                 # http://localhost:9157
```

See `CLAUDE.md` for the full house rules, `PROJECT_BRIEF.md` / `SCOPE.md` for what this site is,
and `tasks/todo.md` for the build plan.
