## Risks
- **`public/styleguide.html` still ships in the build and is publicly reachable at
  `/styleguide.html`.** Irina's security audit flagged this as Low severity, recommended pulling it
  from the deploy before the client-facing domain goes live. Still present as of this pass. Not a
  P5 item and not mine to silently delete from a design-team artifact; flagging it forward.
- **CSP is static, not nonce-based** (a deliberate call in `next.config.mjs`, documented inline):
  the security audit's original proposal was a per-request nonce CSP, but that requires
  `middleware.ts` and would make every route dynamic, giving up the static build. The static CSP
  with `'unsafe-inline'` on `script-src` was accepted instead because this site has no user input,
  no forms, and no third-party scripts — carries no practical XSS surface today. Revisit the day
  analytics or a form is added.
- **Horizon is still unlicensed**, Archivo ships as the stand-in display face (a known, already-
  flagged risk from engineering, not new here).
- Three of five order-online rows and the menu pop-up prices are still "coming soon" — client data
  gaps, not release blockers, tracked in `SCOPE.md` / `tasks/todo.md` "Blocked on client."
