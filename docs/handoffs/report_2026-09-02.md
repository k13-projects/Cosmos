## Evolution
Building an emailed report from the house template surfaced a flaw in the template itself, not in
this project: its scroll-reveal CSS hides content unconditionally and relies on a script to bring
it back, which is exactly the thing every mail client removes. Scoping the hiding rules to a `.js`
class set by the same script, the pattern the Cosmos site already uses, makes a stripped script
harmless instead of fatal. Worth pushing back into
`starter-kit/templates/development-report.html` so no future report ships with it.
