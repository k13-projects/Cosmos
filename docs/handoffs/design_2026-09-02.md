## Risks
- **Horizon is not free.** The display face ships as Archivo at `wdth 125 / weight 900`. It is close
  but not identical: Horizon is slightly tighter and more geometric. Every headline will shift a
  little when the real face lands, so keep headline layout fluid (`clamp()`, no fixed line breaks).
- **White on magenta `#CD1AE0` fails AA at body size (4.36:1).** Mitigated with `--magenta-deep
  #B317C4` for the values band. If anyone repaints that band back to the exact brand hex, the
  accessibility audit will fail. This is the one place the token is deliberately not the guide hex.
- **Yellow-on-magenta and magenta-on-yellow are 3.64:1** — display sizes only. Easy to break by
  reusing the seam-tab styling on a small label.
- **The plate cascade is the hardest piece to make responsive.** Six absolutely-positioned cutouts
  spilling across a band seam will fight the About copy between 640 and 900 px. Budget real time
  for it or drop to three plates on mobile as specced.
- The burger pattern in the styleguide is a hand-drawn SVG stand-in so the file stays
  self-contained. Production must use the client `Background.png` derived into `public/`.
- Transparent PNG cutouts (best sellers, plates) must keep their alpha. Do not let an image
  pipeline flatten them to WebP with a matte.

## 4. Rules that are not negotiable

1. **No raw hex in a component.** Every colour is a token. If a value is missing, add a token.
2. **The values band ground is `--color-magenta-deep`, not `--color-magenta`.** White body copy on
   the brand magenta is 4.36:1 and fails AA. Large display text on true magenta is fine.
3. **Yellow-on-magenta and magenta-on-yellow at 24 px+ only.** Never a paragraph, label, caption or
   nav link. Never yellow text on cream at any size.
4. **Magenta text at body size on cream or tan uses `--color-magenta-ink`.**
5. **Display face is uppercase, 20 px and up, headings only.** Anything smaller is Poppins.
6. **Every control is 44 x 44 px minimum**, focus ring 3 px magenta at offset 3, never
   `outline: none`.
7. **No dead buttons.** A location with no ordering URL renders the "Online ordering coming soon"
   chip, not a link. No invented prices, hours, reviews or contact details.
8. **No em or en dashes in visitor-facing copy** — rewrite with commas. Lorena's copy is otherwise
   verbatim, including "Flavour"/"FLAVOR" and "food near me"; both are flagged to her, not silently
   changed.
9. **Copy lives in `lib/content.ts`** with provenance comments. Components never hardcode strings.
10. **Mobile-first**, tested at 320 / 375 / 430 / 768 / 1024 / 1280 / 1920 plus landscape phone.

brand tokens. Worth repeating on any project whose identity is a single vector mark.
